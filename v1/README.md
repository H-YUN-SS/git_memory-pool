

# MemoryPool V1内存池项目
一个简易内存池实现，用于学习内存管理、减少小对象频繁分配带来的内存碎片，并与系统 `new/delete` 做性能对比。

## 项目结构
```
├── include/      头文件
├── src/          内存池实现
├── main.cpp      测试主函数
├── CMakeLists.txt  编译配置
```

## 编译运行
```bash
mkdir build
cd build
cmake ..
make
./mempool_test
```

## 功能说明
- 实现固定大小内存块的分配与回收
- 减少频繁 `new/delete` 产生的内存碎片
- 支持多线程、单线程性能测试对比
- 使用 C++11 与 CMake 构建

## 测试结果（单线程）
```
===== 测试：内存池 =====
1个线程并发执行10轮次，每轮次newElement&deleteElement 100次，总计花费：144 ms

===== 测试：new/delete =====
1个线程并发执行10轮次，每轮次new/delete 100次，总计花费：66 ms
```

## 性能说明
单线程下内存池略慢于系统 `new/delete`，原因如下：
1.  现代操作系统的 `malloc` 本身经过高度优化，单线程效率很高
2.  内存池需要额外维护内存块链表、查找空闲块，带来一定开销
3.  本项目为基础版实现，未加入线程本地缓存等高级优化
4.  多线程场景下因全局竞争问题，性能会明显下降，更适合单线程环境使用

内存池的主要意义在于**降低内存碎片、控制内存使用、避免频繁系统调用**，而不是单纯追求单线程速度。

## 后续优化方向
- 增加线程本地缓存（Thread Local Cache）
- 实现无锁设计提升并发性能
- 支持多种大小内存块的自适应管理
